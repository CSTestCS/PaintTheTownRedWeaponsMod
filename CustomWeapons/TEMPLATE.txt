# ===========================================================================
#  CUSTOM WEAPON TEMPLATE  (this file itself is ignored by the mod)
# ===========================================================================
#  1. Put your model in this folder, e.g.  MyAxe.fbx
#  2. Copy this file next to it with the SAME name:  MyAxe.txt
#  3. Optional texture with the same name:  MyAxe.png  (or .jpg)
#     If the .fbx has an embedded texture, that is used when there is no .png.
#  4. Start the game. In a level press F9 to reload your files after edits,
#     F8 to spawn every custom weapon in front of you.
#
#  Format: "Setting: value" or "Setting = value". Order, upper/lower case and
#  spaces do not matter. Lines starting with # are comments. Anything you leave
#  out uses the default shown in [brackets].
#  Percentages can be written as 25% or 0.25.
# ===========================================================================
